Cleaning and missing values: dataset/listings.csv
================================================================================
Rows: 77,679 -> 47,695
Columns: 90 -> 78
Cells with missing values: 1,520,187 -> 72,099

Steps taken
--------------------------------------------------------------------------------
1. Filled 32,340 missing bathrooms from the number in bathrooms_text (e.g. '1.5 baths' -> 1.5).
2. Dropped 13 completely empty columns, because they hold no information: neighborhood_overview, host_since, host_response_time, host_response_rate, host_acceptance_rate, host_thumbnail_url, host_neighbourhood, host_total_listings_count, host_verifications, neighbourhood, neighbourhood_group_cleansed, calendar_updated, instant_bookable.
3. Removed 0 duplicate listings (same id).
4. Converted price from text such as '$1,180.00' to a number. It is the price per night in the local currency; the '$' is only formatting.
5. Dropped 29,277 rows without a price. Price is the main variable for analysis, so filling it in would invent the values we want to study. Most of these listings have no available days in the next year, so they cannot be booked anyway.
6. Dropped 225 rows without any host information (host name, superhost status and listing counts were all missing).
7. Removed 482 outlier rows with a price above the 99th percentile (1,875.72). This removes placeholder prices that block bookings, but also some genuine luxury listings.
8. Set 3,389 missing bedrooms to 0 for entire homes named as a studio, because Airbnb often leaves bedrooms empty for studios. Some hosts record their studio as 1 bedroom instead, so studios can have either 0 or 1 bedrooms.
9. Filled 26 missing bathrooms with the median of listings that accommodate the same number of guests.
10. Filled 4,131 missing bedrooms with the median of listings that accommodate the same number of guests.
11. Filled 4,121 missing beds with the median of listings that accommodate the same number of guests.
12. Filled 8,000 missing reviews_per_month with 0, because they belong to listings with no reviews.
13. Added a has_reviews column (8,000 listings have no reviews). Their review scores are left missing, because filling them in would give unreviewed listings a typical score they never got.
14. Filled 16 missing has_availability from availability_365: 't' when the listing has any available days in the next year.
15. Converted the 't'/'f' columns to True/False: host_is_superhost, host_has_profile_pic, host_identity_verified, has_availability.
16. Stored counts such as bedrooms and beds as whole numbers (1, not 1.0).
17. Filled missing text: description and host_about with 'No description', host_location and license with 'Unknown'.
